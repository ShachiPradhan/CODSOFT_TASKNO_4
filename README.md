# CODSOFT_TASKNO_4 — Sales Prediction

This repository contains my submission for **Task 4** of the **CodSoft** internship program. The project is implemented as a Jupyter/Colab notebook (`salesprediction.ipynb`) and focuses on predicting product sales based on advertising expenditure across different platforms.

## 📌 Project Overview

The goal of this task is to build a regression model that can forecast sales from advertising budgets spent on different channels — typically **TV**, **Radio**, and **Newspaper**. The notebook walks through the complete data science workflow, from exploratory analysis to model training and evaluation.
